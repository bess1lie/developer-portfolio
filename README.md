# developer-portfolio

Личный сайт-портфолио разработчика: сайты и автоматизация для малого бизнеса.

## Что внутри

- **index.html** — одна страница: hero, последние проекты, преимущества, технологии,
  услуги, портфолио, open source, стоимость, процесс, FAQ, контакты.
- **assets/css/style.css** — тёмная тема, адаптивность (320–1920px), CSS-переменные.
- **assets/js/main.js** — reveal-анимации, мобильное меню, форма заявки.
- **assets/screenshots/** — реальные скриншоты опубликованных демо-сайтов (WebP).
- **manifest.webmanifest, robots.txt, sitemap.xml** — PWA/SEO-метаданные.

## Стек

Чистые HTML5, CSS3, Vanilla JavaScript. Без зависимостей, CDN и сборщиков.
Сайт полностью работает офлайн.

## Публикация

### Vercel (рекомендуется)

1. Создать репозиторий на GitHub и загрузить файлы.
2. Зайти на [vercel.com](https://vercel.com), импортировать репозиторий.
3. Нажать **Deploy**. Через 30–60 секунд сайт доступен по адресу
   `https://<project-name>.vercel.app`.
4. При необходимости подключить собственный домен в настройках проекта.

### GitHub Pages (альтернатива)

1. Создать репозиторий и загрузить файлы.
2. Settings → Pages → Source: `Deploy from a branch` → `main` → `/ (root)`.
3. Открыть `https://<username>.github.io/`.
