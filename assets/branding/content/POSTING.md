# POSTING.md — что куда постить

## 1. IG посты (карусели)

1. Создать пост → «Выбрать несколько» → загрузить слайды **по порядку** s1 → s2 → … → s6 (для кейсов и how-i-work; одиночные price/errors/checklist/why-solo/site-bot — по одному файлу).
2. Вставить Caption из captions.md (блок поста).
3. Хэштеги добавить в конец caption (они уже включены в блоки captions.md).
4. Ссылку в caption НЕ ставить — она не кликабельна. Вместо этого в caption упоминается «ссылка в шапке профиля».
5. Опубликовать.

## 2. IG Актуальные (Highlights)

1. Профиль → «Актуальное» → значок «+» (новое).
2. Загрузить слайды папки **по порядку**: slide-01 первым (он станет обложкой), затем slide-02…slide-05.
3. Имя актуального — из списка ниже.
4. Сохранить.

| Папка | Имя актуального |
|---|---|
| ig-highlights/price/ | Цены |
| ig-highlights/cases/ | Кейсы |
| ig-highlights/services/ | Услуги |
| ig-highlights/order/ | Заказ |
| ig-highlights/faq/ | FAQ |

Обложка = slide-01-cover.png (тёмная с названием).

## 3. TG-канал

1. Канал → новый пост.
2. Прикрепить обложку tg/*.png.
3. Вставить текст поста из captions.md (раздел «Тексты для TG-канала») — ссылки в нём кликабельные (демо, бот, сайт).
4. Опубликовать.
5. Пост «Цены» (tg/price.png) — закрепить в канале.

## 4. Шапка IG

Проверить, что ссылка в шапке профиля = https://developer-portfolio-six-theta.vercel.app/links (страница со всеми ссылками: сайт, демо, бот).
