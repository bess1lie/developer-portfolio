## Шпаргалка (всегда под рукой)

**Instagram:**
1. Пост → выбрать файлы по порядку из списка → «Добавить»
2. Вписать caption из captions.md (хэштеги уже в конце)
3. Опубликовать
4. Актуальные: Профиль → «Актуальное» → «+» → выбрать слайды по порядку → название

**Telegram:**
1. Пост → прикрепить обложку tg/*.png
2. Текст из captions.md (ссылки уже вставлены)
3. Опубликовать
4. Пост «Цены» (день 8) — закрепить в канале

**Общие правила:**
- Ссылка для IG всегда в шапке профиля → «Ссылки», в caption не дублировать
- Порядок файлов не менять: s1 → s6
- Названия актуальных: Цены / Кейсы / Услуги / Заказ / FAQ
