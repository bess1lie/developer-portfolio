# Прокси на Xiaomi 12 — быстрый вариант (Orbot)

**Итог:** Orbot → большая кнопка → весь трафик защищён. Всё.

## Установка (2 минуты)
1. Файл `orbot-17.9.5-arm64.apk` — перекинуть на телефон
2. Установить (разрешить «установку из неизвестных источников»)

## Включение (10 секунд)
1. Открыть Orbot
2. Нажать большую кнопку START
3. Разрешить системный запрос VPN (VpnService — один раз)
4. Включить тумблер **VPN Mode** → весь трафик через Tor

Одна кнопка: START / STOP. Done.

## HyperOS (чтобы не убивало Orbot)
1. Настройки → Приложения → Orbot → Батарея → **Без ограничений**
2. Там же → Автозапуск → **разрешить**
3. Недавние приложения → Orbot → закрепить (замочек)

## Проверка
Браузер → https://check.torproject.org → «Congratulations». Внешний IP — в Orbot (страна exit-ноды).

## Предупреждения
- Tor **медленный** — это норма, exit-ноды нагружены
- Google Pay/банки через Tor могут не работать → в Orbot: тумблер «Applications» и выбрать приложения, идущие напрямую
- Утечки DNS/IPv6 закрыты самим Orbot (Tor + VPN mode)

# Опция B: домашний Tor-сервер (отложено)

Первоначальный план (весь трафик через свой Tor на ноуте `notepad`):
- Tor на ноуте поднят: `127.0.0.1:9050`, автозапуск включён ✅
- Tailscale установлен, но **не авторизован и служба отключена** — вернуть: `sudo systemctl enable --now tailscaled && sudo tailscale up`
- Клиент: `clash-home.yaml` + `cmfa-2.11.31-meta-arm64-v8a-release.apk` (тоже в этой папке)
- Профиль YAML плейсхолдер заменяется на реальный IP ноута после авторизации

Замечание: чтобы телефон доставал Tor по Tailscale, в `/etc/tor/torrc` надо добавить `SocksListenAddress <tailscale-ip>:9050` + `SocksPolicy accept 100.64.0.0/10` + `reject *` (иначе loopback недоступен из сети + открытый прокси).
